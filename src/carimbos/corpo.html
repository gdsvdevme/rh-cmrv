Câmara Municipal de Rio Verde/GO · carimbe os espelhos de ponto de uma vez e acompanhe a devolução de cada setor

1Espelhos de ponto

Usa a tela Espelho de ponto (FP170) com o órgão Câmara Municipal de Rio Verde. Leva cerca de 1 minuto para o órgão inteiro; marcando Gerar só de uma pessoa você busca por nome ou matrícula e carimba só o espelho dela.

Ou, se preferir, anexe um PDF que você já gerou:

2Escolher o carimbo

3Salvar o PDF carimbado

Também dá para baixar só uma hierarquia, pelo botão Baixar ao lado do nome dela na lista abaixo. Tudo é feito no seu navegador: o PDF não é enviado a nenhum servidor.

Anexe o PDF para começar

A página de cada servidor é reconhecida pela matrícula e pelo nome no topo do espelho.
Depois é só arrastar o carimbo até a posição certa.

Controle de devolução dos espelhos de ponto

Marque, para cada setor ou gabinete, se devolveu o espelho de ponto do mês: devolvido ao RH, devolvido com pendências ou não devolvido, com uma observação se precisar. Em devolvido com pendências, escolha quais servidores do setor ficaram pendentes. Marque também quando o RH entregou o espelho ao setor. As marcações ficam salvas no servidor, mês a mês.
